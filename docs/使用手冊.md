## 1. 三十秒認識

- **一個資料夾 = 一份簡報。** 資料夾裡的每個 `.md` 文字檔就是一張投影片。
- **網站是播放器,資料夾是內容。** 網站不會上傳你的檔案,檔案一直在你的電腦或隨身碟上。
- **不用排版。** 寫好文字,版面自動排好;想調整時再加設定。

## 2. 打開簡報的四種方式

| 方式 | 怎麼做 | 適合 |
|---|---|---|
| **網站** | 用 Chrome 或 Edge 打開 <https://torusmith.github.io/Mdslide-Pile/>,按「開啟本機資料夾」選你的資料夾 | 平常使用;可以編輯存檔 |
| **安裝成 App** | 在網站上,網址列右側的「安裝」圖示 | 想像一般軟體一樣開;裝好後沒網路也能用 |
| **匯出單一 HTML** | 播放時按右上角「匯出」,得到一個 `.html` 檔 | 寄給別人、在沒網路的電腦上報告;雙擊就能播 |
| **下載整個專案** | 在專案資料夾裡起一個本機伺服器(見 README「離線使用」) | 想改程式的人 |

> **注意**:下載下來的 `index.html` **不能直接雙擊**打開(瀏覽器的安全規定),會看到說明畫面。要離線用,請安裝成 App 或用匯出的單一 HTML。
>
> Firefox、Safari 也能播放,但**不能存檔**,而且每次都要重新選資料夾。要編輯請用 Chrome 或 Edge。

## 3. 播放時怎麼操作

### 鍵盤

| 按鍵 | 做什麼 | 按鍵 | 做什麼 |
|---|---|---|---|
| `←` `→` | 上一張 / 下一張 | `Enter` | 放大 / 縮回 |
| `↑` `↓` | 上一章 / 下一章 | `Esc` | 縮回;再按回目錄 |
| `1`–`9` | 跳到第幾章 | `G` | 輸入頁碼,跳到第幾張 |
| `Home` `End` | 第一張 / 最後一張 | `O` | 總覽(所有投影片) |
| `V` | 對照模式(大圖 + 縮圖列) | `L` | 換 3D 排列 |
| `M` | 閱讀模式(整份往下捲,附備註) | `T` | 換主題 |
| `D` | 畫筆與雷射筆 | `X` | 清除這張的畫(畫筆開著時) |
| `E` | 編輯這張 | `S` | 講者視窗 |
| `B` | 黑屏(再按任意鍵回來) | `F` | 全螢幕 |
| `P` | 列印 / 存成 PDF | `K` | 放大時播放 / 暫停本機影片 |
| `R` | 重新載入 | `?` | 說明 |

### 滑鼠與手機

- 點卡片選取,再點一次放大;滾輪也能翻頁。
- 播放時點圖片可以看完整的原圖。
- 手機與平板:左右滑換張、上下滑換章;直拿時會提示轉成橫向。

### 上台小技巧

- **講者視窗(`S`)** 會另開一個視窗:目前這張、下一張、備註、計時。把它拉到自己的螢幕,投影幕上只顯示投影片。
- **翻頁筆**直接能用(它送出的就是方向鍵)。
- **想讓沒到場的人看**:按 `M` 進閱讀模式,把網址傳給對方;或按「列印講義」印成附備註的 A4。

## 4. 做第一份簡報

### 最簡單的版本

1. 在電腦上建一個資料夾,例如 `我的第一份簡報`。
2. 在裡面建一個文字檔 `01-開場.md`,內容:

   ```markdown
   # 大家好

   - 今天要講三件事
   - 大約 10 分鐘
   ```

3. 再建 `02-重點.md`、`03-結論.md`,照樣寫。
4. 打開網站 →「開啟本機資料夾」→ 選這個資料夾。完成。

> 用記事本、VS Code、Obsidian 都可以寫。檔名前面的 `01-`、`02-` 決定順序,畫面上不會顯示。

### 加上章節與標題頁

```
我的第一份簡報/
├─ deck.yml          ← 一行 title: 我的第一份簡報 就好
├─ 01-開場/           ← 資料夾 = 一個章節
│  └─ 01-大家好.md
├─ 02-重點/
│  ├─ 01-第一點.md
│  └─ 02-第二點.md
└─ media/            ← 圖片、影片放這裡
   └─ photo.jpg
```

- 有 `deck.yml` 就會自動產生**標題頁**;每個章節資料夾會自動產生**章節頁**。
- 圖片寫成 `![說明](media/photo.jpg)`,**單獨一行**。

### 講者備註

在投影片最後單獨一行寫 `Note:`,下面的字只有講者視窗和閱讀模式看得到:

```markdown
# 營收成長 35%

Note:
這裡停一下,問大家猜原因。
```

## 5. 編輯模式

播放時按 `E`(或工具列「編輯」)。左邊改文字,右邊即時看結果。

### 上方第一排

| 按鈕 | 做什麼 |
|---|---|
| `‹ 關閉` | 回到播放(有沒存的修改會先問) |
| `‹` `第 3 / 30 張` `›` | 換到上一張 / 下一張,不用關掉再開。**換到別的檔案前會自動存檔** |
| `+ 新增一張` | 在同一章新增一個檔案,自動接續編號 |
| `封存` | 把這個檔案搬到 `_封存/` 資料夾(**不會真的刪掉**,之後可以搬回來) |
| `還原` | 放棄沒存的修改,回到打開時的樣子 |
| `儲存` | 存回你的資料夾(`Ctrl+S` 也可以) |

### 第二排:插入工具

不用記語法,點了就幫你寫:

| 按鈕 | 寫出什麼 |
|---|---|
| 版型 ▾ | 這張用哪種排版(見第 7 節) |
| 標題 | 這一行變成標題;再按一次變小一級 |
| 粗體 | 選取的字變粗體(會用強調色) |
| 清單 | 選取的行變成清單 |
| 圖片 / 影片 ▾ | 列出 `media/` 裡的檔案,點一下插入;也有線上影片網址範本 |
| 分欄 | 插入 `+++`(分欄、多區塊版型用) |
| 新的一張 | 插入 `---`,後面的內容變成新的一張 |
| 備註 | 跳到這張的講者備註;沒有就新增 |
| **外觀 ▾** | 打開外觀設定(下面說明) |

### 外觀設定面板

按「外觀 ▾」,用選的就好:

| 欄位 | 選項 |
|---|---|
| 字級 | 預設 / 小(資料多時)/ 正常 / 大 / 特大 |
| 背景色 | 點色塊選顏色;深色背景字會自動變淺 |
| 背景圖 | 「選圖片…」從 `media/` 挑一張 |
| 圖片遮罩 | 有背景圖才出現:深色(字反白)/ 淺色 / 不加 |
| 強調色 | 粗體、標題線、清單符號的顏色 |
| 文字色 | 通常不用設 |
| 字型 | 可以打字,也可以從清單選 |
| 對齊 | 靠左 / 置中 / 靠右 |
| 欄寬比例 | 左文右圖、分欄、多區塊、多圖並排才出現,例如 2:1 |
| 勾選框 | 逐步顯示、播放時跳過這張、顯示頁尾 |

每個選擇都會在這一張開頭寫一行像 `<!-- size: large -->` 的設定;選回「預設」就刪掉。所有修改都能用 `Ctrl+Z` 復原。

### 截圖標註

這張有圖片時,**在右邊的圖上拖曳**,就會畫出紅框。游標會停在標籤的位置,直接打字(例如「看這裡」)。

### 打字的小功能

| 按鍵 | 做什麼 |
|---|---|
| `Ctrl+S` | 存檔 |
| `Tab` / `Shift+Tab` | 縮排 / 反縮排(可以選好幾行一起) |
| 清單裡按 `Enter` | 自動接下一個符號;空的項目再按一次就結束清單 |
| `Alt+PageUp` / `Alt+PageDown` | 上一張 / 下一張 |
| `Esc` | 關閉編輯 |

### 存檔的安全規則

- 只會改 `.md` 和 `.yml` 檔,不會碰其他檔案。
- 編輯時如果檔案被別的程式改過,會先問你要用哪個版本(預設保留對方的)。
- 不會刪除檔案,「封存」只是搬到 `_封存/`。
- 第一次存檔,瀏覽器會問一次是否允許寫入,按「允許」。

## 6. 設定速查表(可以直接複製)

設定可以寫在三個地方,**越下面的優先**:

| 寫在哪 | 影響範圍 | 寫法 |
|---|---|---|
| `deck.yml` | 整份簡報 | `size: small` |
| 檔案開頭的 front matter | 這個檔案裡的每一張 | 第一行 `---`,寫設定,再一行 `---` |
| 這一張的開頭 | 只有這一張 | `<!-- size: small -->` |

> 用 `<!-- -->` 寫的設定,在 GitHub、Obsidian、VS Code 預覽裡**看不見**,你的檔案仍是乾淨的 Markdown。

### 排版

```markdown
<!-- layout: split -->          版型(見第 7 節)
<!-- step: true -->             清單一項一項出現
<!-- ratio: 2:1 -->             欄寬比例(左:右);分欄可以寫 1:1:2
<!-- align: center -->          文字置中(left / center / right)
<!-- fit: contain -->           圖片完整顯示、不裁切
```

### 字與顏色

```markdown
<!-- size: small -->            字級:small / normal / large / xl
<!-- color: #4f73a6 -->         強調色(粗體、標題線、清單符號)
<!-- text: #222222 -->          文字顏色(通常不用設)
<!-- font: Noto Serif TC -->    字型(電腦上要有)
```

### 背景

```markdown
<!-- background: #1f3a5f -->            背景色(深色時字自動變淺)
<!-- background: media/photo.jpg -->    背景圖
<!-- overlay: dark -->                  背景圖的遮罩:dark / light / none
```

> 寫在 `deck.yml` 或 front matter(YAML)裡時,`#` 開頭的顏色要加引號:`color: "#4f73a6"`。寫在 `<!-- -->` 裡不用。

### 其他

```markdown
<!-- footer: false -->          不顯示頁尾
<!-- hidden: true -->           播放時跳過這張(檔案保留)
<!-- title: 給總覽看的標題 -->   講者視窗與總覽顯示的標題
<!-- mark: 10 20 30 25 看這裡 -->   在圖上畫紅框(數字是百分比:左 上 寬 高)
<!-- mark: 50 50 40 30 #1e88e5 藍框 -->   加 #色碼 換顏色
<!-- chart: line -->            圖表種類:bar / hbar / line
<!-- unit: 萬元 -->              圖表單位
```

### 常用組合

**照片當背景的大字標語**

```markdown
<!-- background: media/photo.jpg -->
<!-- overlay: dark -->
<!-- size: xl -->
<!-- align: center -->
# 一句話講完重點
```

**深色背景的三欄重點**

```markdown
<!-- layout: columns -->
<!-- background: #1f3a5f -->
<!-- align: center -->
# 三個改變

+++
### 速度
**3 天交出原型**
+++
### 成本
**少一半**
+++
### 品質
**錯誤減少**
```

**資料很多的表格**

```markdown
<!-- size: small -->
# 各區業績

| 區域 | Q1 | Q2 | Q3 |
|---|---:|---:|---:|
| 北區 | 120 | 135 | 150 |
```

## 7. 版型一覽

不寫 `layout` 時會自動判斷,大部分情況不用設。

| 版型 | 長怎樣 | 最少要寫 |
|---|---|---|
| `text` | 一般內文 | 標題 + 清單或段落 |
| `center` | 內容置中 | 同上 |
| `split` | 左文右圖 | 文字 + 單獨一行的圖 |
| `split-left` | 左圖右文 | 同上 |
| `full` | 滿版圖片或影片 | 只有一行圖 |
| `quote` | 引言 | `> 引言` 下一行 `— 出處`;再加一張照片 = 右側人像 |
| `number` | 大數字 | `## 68%` 下一行說明 |
| `stats` | 2–4 張數字卡 | `- **68%** 說明` |
| `timeline` | 時間軸 | `- **2024** 事件`,最後一項加 `(now)` |
| `columns` | 分欄比較 | 用單獨一行 `+++` 分欄 |
| `grid` | 多區塊(2×2、3×2 卡片) | 和分欄一樣用 `+++`;區塊裡可以放圖 |
| `flow` | 流程圖 | 清單 = 一列方塊,自動畫箭頭 |
| `gallery` | 多圖並排 | 兩行以上單獨一行的圖 |
| `chart` | 長條圖、折線圖 | 一個表格 |
| `agenda` | 自動大綱 | 不用寫內容 |
| `end` | 結尾頁 | `# 謝謝聆聽` |

### 範例:多區塊 `grid`

```markdown
<!-- layout: grid -->
# 一張放四個區塊

+++
### 寫
![](media/a.png)
一個檔案一張
+++
### 排
資料夾就是章節
+++
### 播
- 3D 牌堆
+++
### 分享
- 匯出 HTML
```

區塊數量自動排:2–3 個一列,4 個 2×2,5–6 個 3×2,7–8 個 4×2。

### 範例:流程圖 `flow`

```markdown
<!-- layout: flow -->
# 處理流程

以前
- 收到信件
- 手打回覆
- 發送

**現在**
- 收到信件
  - 自動比對客戶
- **AI 草稿**
- 主管確認
```

- 清單前單獨一行的字 = 這一列的標籤;整行粗體 = 色塊標籤。
- 整個項目粗體 = 強調色方塊。
- 縮排的子項目 = 方塊下方的小方塊;縮排的一般文字 = 方塊裡換行。

### 範例:圖表 `chart`

```markdown
<!-- layout: chart -->
<!-- chart: bar -->
<!-- unit: 萬 -->
# 每月營收

| 月份 | 營收 |
|---|---:|
| 1 月 | 120 |
| 2 月 | 150 |
```

更多版型的寫法與範例,看[製作專案指南第 5 節](../製作專案指南.md#5-版型)或官方範例簡報。

## 8. 字型

### 預設字型

| 主題 | 標題 | 內文 |
|---|---|---|
| `paper`(紙張)、`ink`(深色) | 襯線體(Noto Serif TC → 思源宋體 → 新細明體) | 黑體(Noto Sans TC → 蘋方 → 微軟正黑體) |
| `slate`(石板) | 黑體 | 黑體 |

英文簡報(`lang: en`)會自動改用英文字型優先。工具**不會從網路下載字型**,用的都是電腦裡已經有的字型;清單前面的字型沒裝,就自動換下一個。

### 換字型

| 範圍 | 寫法 |
|---|---|
| 整份簡報 | `deck.yml` 的 `brand:` 底下寫 `font_display: 標題字型`、`font_body: 內文字型` |
| 某一張 | `<!-- font: 字型名稱 -->`,或編輯模式「外觀 ▾」的字型欄 |

- 只要寫字型**名稱**,例如 `Noto Serif TC`、`Microsoft JhengHei`、`DFKai-SB`(標楷體)。多個用逗號分開,前面的沒有就用後面的。
- 名稱只能有文字、數字、空白、`-`、`_`、`.`。
- **報告用的那台電腦要有這個字型**,不然會換成預設字型。要帶去別台電腦,建議用 Windows 與 Mac 都有的字型,或事先安裝 [Noto Sans TC / Noto Serif TC](https://fonts.google.com/noto)(免費)。
- 匯出的單一 HTML 也不包含字型檔,規則一樣。

## 9. 顏色

### 顏色從哪裡來

優先順序(上面的贏):

1. 這一張的 `<!-- color: ... -->`
2. 章節的顏色(`deck.yml` 的 `sections:` 裡設 `color`)
3. 簡報的強調色(`deck.yml` 的 `accent`)
4. 自動分配(每個章節一個顏色)

強調色會用在:粗體字、標題線、清單符號、時間軸、圖表、卡片邊條。

### 主題

`deck.yml` 寫 `theme: paper`(紙張,米白)、`ink`(深色)或 `slate`(石板,白底藍灰)。播放時按 `T` 可以臨時切換看看。

### 可以寫哪些顏色

- `#4f73a6`(**最推薦**,顏色選擇器給的就是這種)、`#48a`
- `rgb(79, 115, 166)`
- 英文顏色名稱:`teal`、`navy`、`crimson`……

**只有 `#色碼` 和 `rgb()` 能自動判斷深淺**(背景色深時字自動變淺)。用英文名稱或 `hsl()` 當背景色時,請自己加 `text` 指定文字顏色。

為了安全,顏色只接受上面這些格式;寫錯會在檢查時提醒並忽略。

### 配色建議

- 一份簡報用 1 個主色就好,章節顏色用同色系。
- 深色背景配淺色強調色(例如金色 `#d9a441`),淺色背景配深一點的強調色。
- 紅色留給「警告、錯誤、要注意」。

## 10. 請 AI 幫忙

### 讓 AI 做一整份簡報

把 [製作專案指南](../製作專案指南.md) 和你的資料一起給 AI,然後說:

```text
請先完整閱讀 製作專案指南.md。
幫我做一份簡報:
- 主題:<主題>
- 聽眾:<聽眾>
- 長度:<分鐘> 分鐘
- 素材:<數據、圖片、影片網址,或「沒有」>
依照指南第 7 節的步驟產生資料夾與檔案,完成後執行檢查並回報結果。
```

指南第 7 節已經寫好 AI 該怎麼做:先確認需求、不捏造數字、每張都寫備註、至少用 4 種版型、做完要通過檢查。

### AI 會寫哪些「註解」

| 寫法 | 是什麼 | 誰看得到 |
|---|---|---|
| `Note:` 下面的文字 | 講者備註 | 講者視窗、閱讀模式 |
| `<!-- layout: ... -->` 這類 | 這一張的設定 | 播放器(其他 Markdown 軟體看不到) |
| `資料來源:...` 開頭的段落 | 投影片下方的小字註腳 | 所有人 |
| `[^1]` 與 `[^1]: ...` | 腳註 | 所有人 |

### 版型做不到時

流程很複雜、要互動試算、特殊的圖解……可以請 AI 做一個**小型 HTML 檔**放在 `media/`,用 `![說明](media/xxx.html)` 嵌入。規則在指南第 7 節「版型做不到時」:單一檔案、不連網路、配合 16:9。網頁在隔離的框框裡執行,碰不到你的資料夾。

### 請 AI 改一張

```text
這是我的一張投影片(貼上 .md 內容)。
請照 製作專案指南.md 的寫法改成 <想要的樣子>,
只回傳改好的 .md 內容。
```

## 11. 出問題時

| 狀況 | 怎麼辦 |
|---|---|
| 雙擊 `index.html` 停在說明畫面 | 正常,瀏覽器不允許。用網站、安裝成 App,或用匯出的 HTML |
| 順序不對 | 檢查檔名前的數字;建議都用兩位數(`01-`、`02-`) |
| 某張沒出現 | 檔名是不是 `_` 開頭?有沒有寫 `hidden: true`? |
| 圖片顯示「找不到素材」 | 路徑寫 `media/檔名`,大小寫要一樣 |
| 字被切掉 | 編輯模式的預覽會警告「超出投影片」;拆成兩張,或用 `size: small` |
| 不能存檔 | 要用 Chrome / Edge 開「本機資料夾」;網站內建的範例書庫不能存 |
| 影片不能播 | 線上影片需要網路;本機影片建議 mp4、1080p、100 MB 以內 |
| 改了檔案畫面沒變 | Chrome / Edge 會自動更新(約 1.5 秒);其他瀏覽器按 `R` 或重新選資料夾 |
| 設定沒作用 | 按播放畫面工具列的「檢查」,會指出哪裡寫錯 |

還是不行?到 GitHub 開一個 Issue(有範本),附上截圖與檢查結果。
