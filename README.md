# Mdslide Pile

[English](README.en.md) · 繁體中文

**把資料夾變成會動的簡報。** 網站是遊戲機,你的資料夾是遊戲片。

用 Markdown 寫投影片,用資料夾分章節,在瀏覽器裡以 3D 牌堆播放。簡報檔案留在你的電腦或隨身碟裡,網站只負責播放:不用安裝、不用上傳。

**線上使用:** https://torusmith.github.io/Mdslide-Pile/

## 特色

- **資料夾就是結構**:書庫 → 主題 → 簡報 → 章節 → 投影片,所有設定檔都可以省略。
- **本機優先**:直接開啟電腦或隨身碟上的資料夾。Chrome / Edge 會記住你的書庫,下次一鍵重新連線。
- **按需讀取**:先讀目錄,捲到才讀封面,點進去才讀內容,圖片影片快看到時才載入。大量資料也不卡。
- **六種 3D 排列**:牌堆(換章節時洗牌)、封面流、圓柱、螺旋、球體、總覽。
- **三套主題**:紙張、深色、石板。
- **十幾種版型**:圖文、滿版、引言、大數字、數字卡、時間軸、分欄、自動大綱、長條圖與折線圖等。
- **上台工具**:逐步顯示、講者視窗(備註、下一張、計時)、黑屏、全螢幕、翻頁筆、匯出 PDF,也能匯出成單一 HTML 檔(雙擊就能離線播放)。
- **即時更新**:用 Chrome / Edge 開啟的資料夾,改了 MD 檔畫面會自動更新,不用重新整理(也可以按 `R`)。
- **手機與平板**:左右滑換頁、上下滑換章節,轉向時投影片自動重新置中。
- **動畫偏好**:系統設定「減少動態」時自動改用簡化轉場;說明面板(`?`)可以切換「完整 / 簡化」。
- **媒體**:本機圖片與影片,YouTube、Bilibili、Google Drive、Vimeo 嵌入。
- **離線可用**:網站開過一次後,沒有網路也能播放本機簡報。
- **零依賴**:沒有任何第三方套件,也沒有建置步驟,好維護。

## 三分鐘上手

1. 建立資料夾:

   ```
   我的報告/
   ├─ 01-開場/
   │  └─ 01-你好.md
   └─ 02-重點/
      ├─ 01-第一點.md
      └─ 02-第二點.md
   ```

2. 每個 `.md` 檔寫一張投影片:

   ```markdown
   # 標題就是結論

   - 第一點
   - 第二點

   Note:
   這行只有講者看得到。
   ```

3. 打開網站,按「開啟本機資料夾」或直接把資料夾拖進去。按 `Enter` 放大,用方向鍵或翻頁筆翻頁。

完整規則請看 **[製作專案指南.md](製作專案指南.md)**。這份指南也寫給 AI 看,現成的提示詞見下方「[請 AI 幫你做簡報](#請-ai-幫你做簡報)」。

## 請 AI 幫你做簡報

把下面的提示詞複製給任何 AI,改掉 `<尖括號>` 的部分即可。AI 會先讀[製作專案指南.md](製作專案指南.md),再交付一個可以直接放進書庫的簡報資料夾。

### 情況 1:請 AI 自己看新聞

```text
請先完整閱讀這份規則:https://raw.githubusercontent.com/ToruSmith/Mdslide-Pile/main/製作專案指南.md

依規則做一份 Mdslide Pile 簡報:
- 主題:<例如:最近台積電法說會重點>
- 參考新聞:<貼 2–5 則新聞網址;沒有就寫「請自行搜尋最近一週的新聞」>
- 聽眾:<例如:公司同事>
- 長度:<15> 分鐘
- 放在:<01-財經市場>

要求:
1. 數字只能來自你實際讀過的新聞,每張有數字的投影片都要寫「資料來源:」,最後一張列出所有來源連結。
2. 每張都要有講者備註。
3. 交付一個 zip,解壓後就是簡報資料夾(含 deck.yml)。不能產生 zip 的話,就把每個檔案用「檔案路徑 + 程式碼區塊」逐一列出。
```

### 情況 2:附上文件與圖檔

```text
請先完整閱讀這份規則:https://raw.githubusercontent.com/ToruSmith/Mdslide-Pile/main/製作專案指南.md

依規則,用我附上的檔案做一份 Mdslide Pile 簡報:
- 主題:<例如:Q3 專案成果報告>
- 聽眾:<例如:部門主管>
- 長度:<10> 分鐘
- 放在:<02-工作報告>

要求:
1. 內容只能來自我附的檔案,不要補充檔案裡沒有的數字;不確定的地方在講者備註裡標出來。
2. 圖片放進 media/,用原本的檔名引用;適合當重點的圖用滿版或圖文版型。
3. 每張都要有講者備註。
4. 交付一個 zip,解壓後就是簡報資料夾(含 deck.yml 與 media/)。不能產生 zip 的話,就把每個文字檔用「檔案路徑 + 程式碼區塊」逐一列出,圖片由我自己放進 media/。
```

### 小提醒

- 如果 AI 打不開網址,把 `製作專案指南.md` 直接當附件上傳。
- 拿到成果後,用網站開啟資料夾,按「✓ 檢查」就能看到結果(見下方「檢查簡報」)。
- 驗收時看四件事:數字有沒有來源、版型有沒有變化(至少 4 種)、備註是否齊全、交付格式能不能直接用。

## 檢查簡報

做完簡報(自己寫或 AI 做的)後,用下面任一種方式檢查。三種方式用的是同一套規則,結果一樣。

| 方式 | 需要安裝 | 怎麼用 |
|---|---|---|
| 網站的「✓ 檢查」按鈕 | 不用 | 開啟資料夾後,在目錄頁或播放器按「檢查」 |
| 書庫裡的單檔工具 | Node.js | 把 `dist/` 裡的三個檔案複製到書庫根目錄,雙擊「檢查書庫」 |
| 倉庫的檢查腳本 | Node.js + 下載倉庫 | `node scripts/check.mjs <資料夾> --slides` |

檢查內容:設定檔格式、未知的版型、找不到的圖片與影片、圖表裡無法解析的數值、未定義的腳註、張數是否過多,以及每份簡報的版型數量與講者備註覆蓋率。命令列輸出依系統語言,可加 `--lang zh-Hant` 或 `--lang en` 指定。

書庫裡的單檔工具([`dist/`](dist/)):

- `mdslide-check.mjs`:零依賴的單一檔案,放在哪個資料夾就檢查哪個資料夾
- `檢查書庫.cmd`:Windows 雙擊執行
- `檢查書庫.command`:Mac 雙擊執行

想直接拿一個現成的書庫:到 [Releases](https://github.com/ToruSmith/Mdslide-Pile/releases/latest) 下載 `Mdslide-library-v….zip`,解壓後的「Mdslide書庫」資料夾已經放好三個主題、兩份範例簡報與上面的檢查工具。

## 倉庫內容

- `app/`:網站程式(遊戲機本體)
- `content/`:內建書庫。`00-官方範例` 示範所有功能,也是驗收基準
- `製作專案指南.md`:製作簡報的規則(給人與 AI)
- `AGENTS.md`:維護工具本身的說明(架構、原則、如何擴充)
- `scripts/check.mjs`:檢查資料夾是否符合規則
- `dist/`:可以複製到書庫的單檔檢查工具(自動產生)

公開的簡報可以放進 `content/<主題>/` 一起部署;私人或公司內容請留在自己的電腦,用本機模式播放。注意:GitHub Pages 的網站一律公開。

`content/01-財經市場/` 的兩份股市簡報是範例內容,數字截至 2026-11-08,不再更新。

## 開發

只需要 Node 18 以上與任何靜態伺服器,不用 `npm install`:

```bash
node --test tests/*.test.mjs
node scripts/build-catalog.mjs
python3 -m http.server 8000
node scripts/new-deck.mjs content/02-工作報告/2026-11-Q4週報   # 建立新簡報骨架
```

詳細請看 [AGENTS.md](AGENTS.md)。推送到 `main` 後,測試(含 Chrome、Firefox、Safari 核心的瀏覽器測試)全部通過才會自動部署到 GitHub Pages(第一次需要在 Settings → Pages 把 Source 設成 **GitHub Actions**)。
