# 資料夾就是結構

```
我的書庫/
├─ 01-教學/                 ← 主題
│  └─ 2026-11-讀書會/        ← 一份簡報
│     ├─ deck.yml           ← 標題、日期、主題(可省略)
│     ├─ 01-問題/            ← 章節
│     │  ├─ 01-現況.md       ← 投影片
│     │  └─ 02-數據.md
│     └─ media/             ← 圖片與影片
└─ 02-工作/
```

Note:
數字前綴決定順序,畫面上會自動拿掉。底線開頭的檔案(例如 _草稿.md)會被略過。
