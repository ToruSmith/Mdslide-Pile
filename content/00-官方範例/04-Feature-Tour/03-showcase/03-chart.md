# Charts handle negative and missing values

| Month | Profit |
|---|---|
| Jan | 120 |
| Feb | −80 |
| Mar | N/A |
| Apr | 60 |
| May | −30 |
| Jun | 150 |

Illustrative data. Missing values show as "–".

Note:
Chart layout: write a table; values may use separators, minus signs, % and units.
